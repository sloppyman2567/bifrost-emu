Run ARM64 Android games and Linux apps on your x86_64 Linux PC

bifrost-emu lets your Linux PC run games and apps made for ARM64 phones and boards: Android games straight from their APK, and ARM64 Linux programs. They run on your own graphics card, sound and controllers, with no phone and no virtual machine. It is free and open source, and still experimental: games can crash, run slowly or not start.

What it does

Games built for ARM64 run on an ordinary x86_64 Linux PC, as if they were made for it.

Android games from an APK

Run bifrost-emu game.apk and it installs and starts the game, on a real Android 15 system that runs on your desktop.

ARM64 Linux programs too

Games and tools built for ARM64 Linux, the kind made for phones and single-board computers, start like any other program.

Your graphics card

OpenGL and Vulkan go straight to your own GPU, and Android windows draw at your monitor's full resolution.

Controllers, keyboard and mouse

Gamepads work as an Xbox-style controller, and the mouse stands in for touch.

Fast where it works

ARM code is translated into native PC code while the game runs. Some games reach about 60 FPS; others are still slow.

Free

Open source and in the public domain (Unlicense).

Install

From a fresh clone, one command installs the host packages, builds the emulator and sets up the Android runtime under ~/.local (about 1.5 GB of pinned downloads).

git clone $repo && cd bifrost-emu
make bootstrap

Then run an Android game or an ARM64 Linux program:

bifrost-emu game.apk          # installs and runs an Android app
bifrost-emu ./program-arm64   # runs an ARM64 Linux binary

Needs an x86_64 CPU with SSE4.1 and FMA3. Distribution support, Debian packages and Bazzite/Distrobox steps are in the support matrix and the quick start.
