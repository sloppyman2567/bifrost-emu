Run ARM64 Android games and Linux apps on your x86_64 Linux PC

bifrost-emu lets your Linux PC run games and apps made for ARM64 phones and boards: Android games straight from their APK, and ARM64 Linux programs. They run on your own graphics card, sound and controllers, with no phone and no virtual machine. It is free and open source, and still experimental: games can crash, run slowly or not start.

Run Android games and ARM64 apps on Linux

Games built for ARM64 run on an ordinary x86_64 Linux PC, as if they were made for it.

Android games from an APK

Run bifrost-emu game.apk and it installs and starts the game, on a real Android 15 system that runs on your desktop.

ARM64 Linux programs too

Games and tools built for ARM64 Linux, the kind made for phones and single-board computers, start like any other program.

Your graphics card

OpenGL and Vulkan go straight to your own GPU, and Android windows draw at your monitor's full resolution.

Controllers, keyboard and mouse

Gamepads work as an Xbox-style controller, and for apps that only take touch a gamepad can act as a cursor too: the left stick moves it and A taps. The mouse stands in for touch.

Fast where it works

ARM code is translated into native PC code while the game runs. Some games reach about 60 FPS; others are still slow.

Common questions

What is bifrost-emu?

A free, open-source user-mode emulator for ARM64 (AArch64) Linux. A JIT compiler translates ARM64 code to x86_64 as it runs, so Linux programs and Android apps made for ARM run on an x86_64 Linux PC.

Can I run Android games on Linux without a phone?

Yes: bifrost-emu game.apk installs and starts the game on a real Android 15 system (Asgard) that runs on your desktop. No phone, no virtual machine and no Android image to flash. Install steps.

How is it different from Waydroid?

Waydroid runs a full Android system in a Linux container and needs binder support in the host kernel. bifrost-emu emulates ARM64 itself and provides its own virtual /dev/binder, so it needs no container and no Android kernel modules.

Is it like qemu-user?

For Linux programs, yes: it plays the part of qemu-aarch64 user-mode emulation, without needing QEMU, and adds the Android runtime and GPU, audio and input forwarding.

Which games work?

$playable of $games recorded games are playable, as reported by the maintainer; see the compatibility list for each game's status and what is not confirmed.

What does it run on?

x86_64 Linux with SSE4.1 and FMA3. ARM hosts, Windows and macOS are not supported. It is experimental: games can crash, run slowly or not start.
