Install bifrost-emu on Linux to run Android games and ARM64 apps

bifrost-emu runs on x86_64 Linux and is experimental. The one-command install below is new and has not been confirmed on every distribution; the support matrix says what has been checked.

Requirements

An x86_64 Linux PC with SSE4.1 and FMA3 (the JIT refuses to start without them; --no-jit runs on any x86-64 CPU). A GPU with OpenGL or Vulkan drivers, and about 1.5 GB to download plus about 1.1 GB on disk for the Android runtime. Android windows use SDL3: where the distribution has none (Debian 12 and 13, Ubuntu 24.04) bootstrap builds it, and the Debian and Ubuntu package route below needs Debian or Ubuntu 25.10 or newer for Android windows.

One command

From a fresh clone this installs the host packages (apt, dnf, zypper or pacman; it asks for sudo only if some are missing), builds the emulator, then downloads and installs the Android runtime (Asgard) under ~/.local:

git clone $repo && cd bifrost-emu
make bootstrap       # about 1.5 GB of pinned downloads; PREFIX=DIR to install elsewhere

Add ~/.local/bin to your PATH for the bifrost-emu and asgard commands. On a minimal system without make or Python, run Scripts/Setup/install-deps.sh first. An interrupted download is kept and the next run resumes it.

Run something

bifrost-emu game.apk          # installs and runs an Android app (.apk .apkm .apks .xapk)
asgard launcher               # desktop library of installed apps
bifrost-emu ./program-arm64   # runs an ARM64 Linux binary

Dynamically linked Linux programs need a guest root filesystem: bifrost-emu --setup-rootfs installs one (about 235 MB), and --setup-rootfs --games adds the libraries Linux games need. Android apps do not use it. See the rootfs guide.

Debian and Ubuntu package

Build the packages from the clone, then install them:

sudo apt install build-essential debhelper pkg-config libavcodec-dev libavutil-dev libswscale-dev \
     libegl-dev libffi-dev libgl-dev libsdl3-dev libsdl2-dev libwayland-dev libx11-dev
make deb
sudo apt install ../bifrost-emu_*.deb ../bifrost-emu-asgard_*.deb
asgard-setup                  # once: about 1.5 GB of downloads
bifrost-emu --setup-rootfs    # once, for Linux programs

Bazzite and other immutable Fedora

Build and run inside a Distrobox container, since the emulator links the container's libraries:

distrobox create --name bifrost --image registry.fedoraproject.org/fedora-toolbox:44
distrobox enter bifrost
make bootstrap

Updating and removing

After pulling new code, run the same make bootstrap again: only the files that changed are copied. The APK guide covers updates, per-app settings and asgard commands. If Bifrost is already installed elsewhere, such as /usr/local, bootstrap makes a second copy that takes over when ~/.local/bin comes first on your PATH.

Full details, including building only the emulator and every option, are in the README quick start. Something not working? See the games list for what has run, and open an issue.
