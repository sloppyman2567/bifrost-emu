# simd_dp.txt — SIMD data-processing decode/classify spec.
# GENERATOR INPUT (single source of truth). Format:
#   NAME  MASK            MATCH           FAMILY    IRSUB   GUARD
# MASK is ANDed onto the raw op; result must equal MATCH. IRSUB is the
# per-family semantic sub-opcode consumers emit/execute. GUARD is a C++
# boolean expr with `op` (uint32_t) and `size`/`Q`/`U`. First match wins.
#
# Family -> IRSUB meaning:
#   INT_ARITH = SIMD_ARITH op (0..6 = ADD/SUB/MUL/UMIN/UMAX/SMIN/SMAX)
#   INT_CMP   = SIMD_CMP op   (0 = CMEQ, 1 = CMGT, 2 = CMGE, 3 = CMHI, 4 = CMHS)
#   LOGIC     = SIMD_LOGICAL op (0..4 = AND/ORR/EOR/BIC/ORN); native Q=1
#   FP        = SIMD_FP op (0..7 FADD..FMINNM, 0xB FMULX, 0xD FABD,
#                            0xE FMLA, 0xF FMLS)
#   SHIFT     = shift kind (0..6 = SHL/USHR/SSHR/USRA/SSRA/SLI/SRI)
#   DUP       = GPR->vector DUP (native, all element sizes)
#   CRYPTO    = AES_CRYPTO sub (0..3 AESE..AESIMC, 4 PMULL, 5 PMULL2)

# ── AdvSIMD modified immediate (MOVI/MVNI/ORR/BIC + MSL) ────────────────
# Encoding: 0 Q op 01111 0 000 abc cmode o2 1 defgh Rd (bit9+1 const).
# MUST precede the SHIFT rows: the 32-bit SHL/USHR/SSHR bases share
# bits[31:24]=0x0F and bits[11:10]=01, so they match this mask too. They are
# distinguished by the immh guard bits[22:19]==0 — valid shifts always set
# immh (shift amount), while MOVI/MVNI/ORR/BIC/MSL never do (bits[22:19]
# hold the fixed 0000 prefix). No SHRN exclusion (bits[15:10]=0x21) is
# needed: every valid SHRN has immh (bits[22:19]) >= 1, so the immh==0 guard
# already separates it; a crude bits[15:10] clause would REJECT cmode=8 MOVI
# (16-bit LSL #0, whose bits[15:10] = 1000 o2 1 = 0x21 == the SHRN opcode).
# FMOV (cmode=0xF) stays on the interpreter. The interpreter block is the
# semantic reference.
MOVI    0x9F800C00   0x0F000400   MODIMM    0   ((op >> 19) & 0xF) == 0

# ── UMOV (vector element -> GPR) ─────────────────────────────────────────
# Encoding: Q 0 0 01110 size 1 imm5 0 0 1 1 Rn Rd. Element size/index come
# from imm5 (esize = 1 << ctz(imm5), index = imm5 >> (ctz+1)); the `size`
# field (bits[23:22]) is 00. The ASIMDINS group shares this mask with INS
# (bits[15:12]=0001 -> 0x0E001C00) and SMOV (bits[15:12]=0010 ->
# 0x0E002C00); UMOV's bits[15:12]=0011 -> 0x0E003C00 selects it alone.
# Q=0 -> Wd (32-bit GPR, zero-extended), Q=1 -> Xd (64-bit). The interp
# (interp_fp.cpp case 0x0E003C00) is the semantic reference. The game's
# memset does `umov x1, v0.d[0]` (0x4E083C01) right after `dup v0.16b,w1`
# to read the broadcast back — native here avoids the interp round-trip.
UMOV    0xBFE0FC00   0x0E003C00   UMOV       0   -

# ── PMISC: CNT/NOT/RBIT/ABS/NEG (2-reg misc) ─────────────────────────────
# CNT/NOT/RBIT share sub2 0x0E205800 (interp collapses them) but differ in
# U (bit29) and size[0] (bit22). Mask 0xBFE0FC00 keeps U, size, bit21 and
# bits[15:10] so each gets a distinct row:
#   CNT  = 0x0E205800 (U=0, size=0) — popcount per byte
#   NOT  = 0x2E205800 (U=1, size=0) — bitwise invert
#   RBIT = 0x2E605800 (U=1, size=1) — bit-reverse per byte
# ABS/NEG share sub3 0x0E20B800 but FCVTZS/FCVTZU also match that base with
# bit16 (0x10000) set, so mask 0xBF21FC00 keeps bit16 and strips size:
#   ABS = 0x0E20B800 (U=0), NEG = 0x2E20B800 (U=1)
# ABS of INT_MIN returns the input unchanged (ARM semantics).
CNT     0xBFE0FC00   0x0E205800   PMISC      0   -
NOT     0xBFE0FC00   0x2E205800   PMISC      1   -
RBIT    0xBFE0FC00   0x2E605800   PMISC      2   -
ABS     0xBF21FC00   0x0E20B800   PMISC      3   -
NEG     0xBF21FC00   0x2E20B800   PMISC      4   -

# ── CVTF: vector integer <-> FP converts (2-reg misc) ────────────────────
# SCVTF/UCVTF (int->fp) match 0x0E20D800/0x2E20D800 with size 0/1. CRITICAL:
# FRECPE/FRSQRTE share these exact sub3_noq values but use size 2/3 — the
# `size == 0` guard is what keeps them on the interpreter. size==1 (2D/1D,
# 64-bit ints) stays interp too (no vector 64-bit int<->fp in SSE2/AVX2).
# FCVTZS/FCVTZU (fp->int) match 0x0E21B800/0x2E21B800 (bit16 set on the
# ABS/NEG base); guard size == 2 (4S/2S native), size==3 (2D/1D) stays
# interp. NaN -> 0, out-of-range saturates.
SCVTF   0xBF20FC00   0x0E20D800   CVTF       0   size == 0
UCVTF   0xBF20FC00   0x2E20D800   CVTF       1   size == 0

ADDP    0xBF20FC00   0x0E20BC00   ADDP       0   size == 0

# ── XTN family (vector narrowing) ────────────────────────────────────────
# bits[15:10]: 001010 -> XTN (U=0) / SQXTUN (U=1); 010010 -> SQXTN (U=0) /
# UQXTN (U=1). size selects the SOURCE element size (2x the dest): 0 -> 16b
# src/8b dst, 1 -> 32/16, 2 -> 64/32. Always reads the FULL 128-bit source.
# Q=0 writes low 64 bits + zeroes high; Q=1 (the *2 variants) writes the
# HIGH 64 bits preserving the low half. size==3 is a DecodeError.

SQXTUN  0xBF20FC00   0x2E202800   XTN        1   size < 3

# ── TBL/TBX (vector table lookup, 1-2 source regs) ───────────────────────
# Encoding: 0 Q 0 0 1110 size 0 0 Rm op2 L Rn Rd. op2 = bit12 (TBX), L =

# ── INS (element, vector) ────────────────────────────────────────────────
# Same 0x2E000000 prefix as EXT but bit10 (0x400) is 1 (EXT keeps bit10=0,
# putting imm4 in bits[14:11]). imm5 (bits[20:16]) encodes the dest element
# size + index; lowest set bit = esize, upper bits = dest index. Guard keeps
# imm5 low nibble non-zero so esize is 1/2/4/8 (imm5=0/0x10 -> DecodeError
# stays on the interp). src element index = bits[14:11] / esize.
# GCC lowers vextq_u8 to a 2-source TBL whose index vector is built with
# these INS moves — native here avoids the interp round-trip.
INS     0xBFE00400   0x2E000400   INS        0   ((op >> 16) & 0x0F) != 0

# ── PAIRMIN: SMAXP/SMINP/UMAXP/UMINP (pairwise max/min) ────────────────
# Encoding: 0 Q U 01110 size Rm 01101 0 Rn Rd (3-register same, like
# ADD/SUB). Empirical from gas (matches interp_fp.cpp case 0x2E20A400):
#   SMAXP=0x0E20A400, SMINP=0x0E20AC00, UMAXP=0x2E20A400, UMINP=0x2E20AC00
# (size=0 shown; the size bits[23:22] are masked off so one row covers all
# sizes). bit11 = max(0)/min(1), bit29 (U) = signed(0)/unsigned(1). IRSUB =
# subop (0=SMAXP, 1=SMINP, 2=UMAXP, 3=UMINP). Mask keeps U(29),
# bits[28:24]=01110, bit21 and bits[15:10] (0x29/0x2A/0x2B) so min/max and
# signed/unsigned are distinct rows. size==3 (.1d/.2d) is NOT a valid
# encoding — gas rejects it (pairwise needs >= 2 elements), so the masked-off
# size bits harmlessly cover sizes 0-2. Semantics: BOTH sources always
# contribute — Q=1 -> Vd = pairwise(Vn) ++ pairwise(Vm) (16 bytes);
# Q=0 -> Vd low 8 bytes = pairwise(Vn) ++ pairwise(Vm) (8 bytes, real-ARM;
# the Vm half is NOT zeroed — see AGENTS.md Q=0 pairwise note).
SMAXP    0x3F20FC00   0x0E20A400   PAIRMIN    0   -
SMINP    0x3F20FC00   0x0E20AC00   PAIRMIN    1   -
UMAXP    0x3F20FC00   0x2E20A400   PAIRMIN    2   -
UMINP    0x3F20FC00   0x2E20AC00   PAIRMIN    3   -
